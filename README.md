# 헤어핏

미용실 방문 전 나에게 맞는 헤어스타일을 찾아보는 앱인토스 미니앱 프로젝트.

현재 범위: 사진 업로드, 취향 입력, 입력 요약, 추천 스타일 선택 및 상담 메모. 기본 모드는 예시 추천입니다. Gemini 실제 연결 코드는 준비했으며 키 설정 후 테스트할 수 있습니다. 이미지 생성은 아직 연결하지 않았습니다.

## 실행

Node.js 24 LTS 기준.

```sh
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다.

```sh
npm test
npm run build
```

## 1차 확인 사항

1. JPG/PNG/WEBP 사진을 선택하면 미리보기가 나오는지 확인합니다.
2. 사진 교체·삭제, 10MB 초과 파일 및 잘못된 파일 안내를 확인합니다.
3. 자동 추천과 직접 지정 모드를 바꾸고 조건을 선택합니다.
4. 직접 지정 모드에서는 스타일을 입력해야 다음으로 넘어갈 수 있습니다.
5. 요약에서 선택값이 맞는지 확인하고 이전 화면에서 수정합니다.
6. 좁은 모바일 크기에서도 화면을 확인합니다.

사진과 입력은 브라우저 메모리에만 존재하며 새로고침 시 사라집니다. 예시 모드에서는 취향 텍스트만 로컬 서버로 전달합니다. 실제 Gemini 모드에서는 동의 후 취향 텍스트를 Google API로 전송합니다. 어떤 모드에서도 현재 사진은 서버로 보내지 않습니다.

## 2차 확인 사항

사진 선택 → 취향 입력 → 입력 요약 → 스타일 선택으로 → 예시 추천 불러오기 → 3개 중 1개 선택 → 선택한 스타일 확인.

직접 지정 모드는 입력한 스타일 1개를 표시합니다. 취향 다시 입력하기로 돌아가면 이전 추천 및 선택은 폐기하고 새 요청으로 시작합니다. 테스트용 `docs/qa/upload-test.png`는 개인 정보가 없는 1픽셀 PNG입니다.

## 실제 Gemini 추천 테스트

`.env.example`을 `.env.local`로 복사하고 `VITE_RECOMMENDATION_MODE=gemini`, `GEMINI_API_KEY`를 설정한 뒤 개발 서버를 재시작하세요. 키에는 `VITE_` 접두사를 붙이면 안 됩니다. 키는 서버의 개발 미들웨어에서만 읽습니다. 채팅에 붙여 넣지 마세요.

현재 모델은 `gemini-3.1-flash-lite`이며 취향 기반 텍스트 추천입니다. 사진 분석은 아직 없습니다. 실제 API 호출 비용과 제공자 데이터 정책은 사용자 계정 설정에 따릅니다. 키 없는 상태에서 실연결 성공을 검증하지 않았습니다.

## 앱인토스 및 Workers

```sh
npm run dev:toss
npm run build:toss
npm run build:worker
npm run dev:worker
```

`build:toss`는 `hair-fit.ait`를 만듭니다. 업로드 전 `apps-in-toss.config.ts`의 appName을 콘솔 등록값으로 변경하세요. 기본 `dev`는 브라우저용 Provider, `dev:toss`는 플랫폼 Provider와 공식 모의 테스트 도구를 사용합니다. 토스앱 실기기 검증은 별도로 필요합니다.

`build:worker`는 배포 없는 빌드 검증입니다. 실제 배포는 수행하지 않았습니다. 배포 전 서버의 `GEMINI_API_KEY` secret과 `ALLOWED_ORIGIN`을 실제 앱 출처로 설정하고, 클라이언트의 `VITE_RECOMMENDATION_API_URL`에 서버 endpoint를 설정해야 합니다. CORS는 인증이나 과금 방어가 아니므로 공개 전 요청 제한 및 접근 제어도 필요합니다. 프로덕션은 AI 미설정 시 503을 반환하며 예시로 대체하지 않습니다.

이미지 편집의 공통 호출 및 업체별 연결 구조는 `docs/image-provider-design.md`에 정리했습니다. 실제 Google·fal.ai·OpenAI 이미지 어댑터는 다음 작업 단위입니다.

현재 앱 이름은 임시 이름입니다. 진행 범위는 `docs/PROGRESS.md`를 참고하세요.
