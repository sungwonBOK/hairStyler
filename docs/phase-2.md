# 2차 작업 계획

사용자 승인: 1차 화면을 확인했고 다음 큰 작업 단위 진행 요청.

## 이번 확인 범위
- 앱인토스 SDK 설치 및 빌드 설정. 등록 전 임시 appName은 hair-fit.
- Workers POST /api/recommendations 요청/응답 규격 및 서버 입력 검증.
- 사용자가 추천용 Gemini 3.1 Flash-Lite, 이미지용 Nano Banana 2.1 선택. 키 미설정 시 명확한 예시 응답만 사용. 이번에는 취향 텍스트 기반 추천까지 연결 코드를 구현하며 사진·얼굴 분석은 다음 보완 단위.
- 추천 3개 설명·관리 난이도·상담 참고사항 및 1개 선택. 직접 지정은 입력한 1개 선택.
- 로딩·실패·재시도·이전 입력 수정·선택 무효화.
- Gemini 실제 추천 어댑터와 동의 확인 구현. 실제 호출은 키 설정 후 별도 검증.
- 추가 요청: editHairstyle 공통 함수 및 Google/fal/OpenAI 어댑터 계약 구현. 이미지 업체 실제 연결은 다음 단위.

## 구현 순서
1. 서버 계약 테스트: 잘못된 입력 거절, 자동 3개, 직접 1개, 실서비스 모드에서 예시 오인 방지.
2. 공용 요청·응답 타입 및 검증, Workers 핸들러, 로컬 프록시.
3. 추천 화면 및 선택 상태, 요청 중 중복 클릭 방지, 오류와 재시도.
4. 앱인토스 패키지 실제 API 확인 후 설정, 일반 브라우저와 플랫폼 빌드 분리.
5. 전체 테스트·프론트 빌드·앱인토스 번들·Workers 빌드 검증, 사용자 확인 대기.

## 제한
이번 단위는 이미지 생성 미포함. Cloudflare 계정 배포 및 토스 콘솔 등록/실기기 테스트는 하지 않는다. AI 공급자가 정해지지 않은 상태를 실제 추천 연결 완료로 표현하지 않는다.
