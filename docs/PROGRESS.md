# 헤어핏 개발 체크포인트

사용자가 큰 작업 단위마다 직접 테스트하고 확인한 후 다음 단계로 진행한다.

## 1차 — 사진과 취향 입력
- React 18 + TypeScript + Vite, TDS 기본 컴포넌트
- 사진 선택·미리보기·교체·삭제
- 파일 형식·10MB 제한·이미지 디코딩 오류 처리
- 자동 추천 / 직접 지정, 길이·펌·앞머리·모질·손질 시간·추가 요청
- 입력 요약과 이전 단계 수정
- 브라우저 메모리에만 사진 보관. 새로고침하면 초기화
- 사용자 확인 완료. 2차 작업 진행 승인받음

### 검증 기록
- 파일 미선택·잘못된 형식·10MB 초과를 막는 자동 테스트 3개 통과
- TypeScript 검사 및 배포용 빌드 통과
- 로컬 브라우저에서 첫 화면 표시 확인
- TDS 패키지로 인해 번들 용량 경고가 있음. 출시 준비 시 최적화 필요
- 사진을 사용한 전체 흐름과 실제 모바일 기기 확인은 사용자 체크포인트에서 수행

## 2차 — 추천 선택 및 연동 기반
- 앱인토스 SDK 3.10, TDS 전용 Provider, 공식 개발 도구 설정
- hair-fit.ait 번들 생성 확인. appName은 임시값이며 콘솔 등록 및 실제 토스앱 확인 필요
- Workers 요청 검증, 8KB 요청 제한, 오류 정규화, 캐시 방지, 허용 출처 설정
- 기본 미리보기는 예시 추천. 자동 3개 / 직접 지정 1개, 상담 메모 및 선택
- 실제 Gemini 3.1 Flash-Lite 추천 어댑터와 서버 전용 키 설정 준비
- 현재 실제 추천은 취향 텍스트 기반. 사진·얼굴 분석은 아직 미연동
- 동의 후에만 텍스트 외부 제공. 예시 결과와 Gemini 결과를 구분
- 공통 editHairstyle 함수와 Google/fal/OpenAI 어댑터 계약·선택·오류 처리 구현
- 이미지 공급자 실제 어댑터는 다음 단위. 자동 전환·자동 재시도 없음
- 사용자 확인 대기. 실제 Google 호출은 키가 없어 검증하지 않음
- 검증: 자동 테스트 26개 통과, 앱인토스 번들·브라우저·Worker 빌드 통과. 1픽셀 테스트 이미지로 사진 선택 → 단발 조건 → 예시 추천 → 태슬 단발 선택 → 상담 메모까지 브라우저 확인
